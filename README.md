# 📋 Assessment NR-1 — Riscos Psicossociais

**MindESG · MindInnovation**

Assessment completo para mapear a maturidade da sua empresa em riscos psicossociais (NR-1) e identificar oportunidades de automação com agentes de inteligência artificial.

## O que avalia

- Dados da empresa e contexto organizacional
- Maturidade em NR-1 / GRO (PGR, inventário de riscos, metodologias)
- Indicadores operacionais (absenteísmo, turnover, afastamentos CID F)
- Processos atuais de gestão de riscos psicossociais
- Maturidade digital e tecnológica
- Oportunidades de automação com AI
- Mapa completo de Normas Regulamentadoras (NRs)
- Modelo de decisão e expectativas

## Resultado

- Score de maturidade NR-1 (0-100) com classificação
- Relatório PDF personalizado
- Dados enviados automaticamente para a equipe MindESG

## Contexto regulatório

Desde 26/05/2026, a gestão de riscos psicossociais é obrigatória no PGR (Portaria MTE 1.419/2024).

Site estático (HTML) hospedado no Vercel com webhook para Google Sheets.
